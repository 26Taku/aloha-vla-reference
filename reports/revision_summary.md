# 初学者向け教材への改訂要約

## 改訂方針

従来版は、用語説明を追加したことで検索性は高まった一方、説明の順序が技術項目中心で、ロボット未経験者が最初の具体的な成功体験へ到達しにくい構成だった。

本改訂では「用語を先に網羅する」のではなく、次の学習経路へ再設計した。

1. ALOHAで何を記録するのかを、ブロック移動の例で理解する。
2. Hardwareとsoftwareの役割を、操作からDatasetまでの流れに沿って理解する。
3. Armとcameraを実物から識別し、短いepisodeを収録する。
4. 実機検証値と比較して、自分の結果が妥当かを判断する。
5. 追加sensorの例から、未知の機器を自分で調べる順序を学ぶ。

## 主な変更

| 対象 | 変更内容 |
|---|---|
| README / 00 | 読者、最初の到達点、学習順序、問題切り分けの地図を明示 |
| 01 | Software名の比較から始めず、1回の収録を支える五つの役割から説明 |
| 02 | ブロック移動の1 episodeを題材に、各Stepを目的・実行・意味・完了条件で構成 |
| 03 | 抽象的な責任境界から始めず、力覚sensorの具体例から保存方式と同期判断を導出 |
| 04 | 症状indexと層別の調査順序を追加 |
| 05 | 初回構築後に使う変更・再検証の章として位置づけを明確化 |
| 06 | 実機検証を報告証跡だけでなく、利用者が正常性を判断する比較基準として再構成 |
| 詳細資料 | 本文と重複していた旧referenceを削除し、付属sensor script固有の仕様だけを`examples/`に残した |

## 実機検証の扱い

実機検証結果は利用者向け本文から切り離していない。02・03の各完了条件から06へ参照し、frame数、rate、missing、future、ageなどを自分の結果と比較できるようにした。

一方、納品時の確認事項や改訂経緯は`reports/`に置き、通常の利用者が読む教材本文には含めていない。

## 技術内容への影響

本改訂はdocumentation構成を中心とする。検証済みsoftware version、Dataset schema、hardware識別方法、sensor alignment algorithm、実測値は変更していない。
